## Live Website
https://adithya25-hub.github.io/Campus-Lost-and-Found-/


GCET Campus Lost & Found is a modern web-based platform designed for students of Geethanjali College of Engineering and Technology to report, track, and recover lost items across campus.

The system allows students to submit lost and found reports, search existing listings, and receive real-time activity updates about items discovered around campus. A verification-based claim system enables students to request ownership of found items, while smart matching helps identify potential matches between lost and found reports.

The platform is built with a modern product-style interface inspired by leading tech websites, featuring smooth animations, structured dashboards, and a clean user experience.

Key features include:

• Secure login using GCET student email (@gcet.edu.in)  
• Separate sections for lost and found items  
• Detailed campus location reporting (blocks, classrooms, labs, and facilities)  
• Smart lost–found matching suggestions  
• Item claim and verification workflow  
• Real-time campus activity feed  
• Search and filtering system  
• Modern responsive UI with smooth animations

This project aims to provide a practical campus utility while demonstrating modern web development practices and product-level interface design.
